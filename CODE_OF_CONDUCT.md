# Code Of Conduct

Everyone participating in Harn is expected to treat other people with respect in issues, pull requests, discussions, and related project spaces.

Be direct, technical, and constructive. Assume good intent where possible, and focus criticism on code, behavior, documentation, and decisions rather than people.

Harassment, threats, sustained personal attacks, and deliberately disruptive behavior are not welcome.

If a discussion is getting unproductive, step back, clarify the technical disagreement, and keep the project moving.
